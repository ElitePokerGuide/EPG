# Formats

Each format is a template the generator fills from one concept card. One card can feed several formats.

| id | file | platform | length | notes |
|---|---|---|---|---|
| mistake-fix | mistake-fix.md | IG Reels, TikTok, YT Shorts | 30-45 s | hook -> mistake -> why -> fix -> CTA |
| quiz | quiz.md | IG Reels, TikTok | 20-30 s + answer | needs example_hand; answer posted next day or pinned |
| schools-disagree | schools-disagree.md | IG carousel, TikTok photo mode | 8-10 slides | needs contradictions or 2+ source_refs |
| concept-60 | concept-60.md | IG Reels, TikTok, YT Shorts | 55-60 s | one concept, one example, one takeaway |
| myth-fact | myth-fact.md | Reel or carousel | 30 s / 6 slides | needs common_mistake |
